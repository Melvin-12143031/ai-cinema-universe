# 🎬 AI Cinema Universe

### Where artificial intelligence meets the art of storytelling.

**Discover. Explore. Experience AI Cinema.**

AI Cinema Universe is a cinematic web platform built for exploring AI-generated films, discovering new stories, and keeping track of films you want to watch.

Designed with a modern, immersive interface, the platform brings film discovery, detailed movie information, viewing options, and a personal watchlist together in one experience.

## ✨ Features

- 🎥 **Cinematic Hero Section** — A visually immersive landing section with a cinematic background and featured content.
- 🍿 **Film Discovery** — Browse a curated collection of AI-generated films.
- 🔎 **Search & Filtering** — Find films using the available search and filtering options.
- ↕️ **Sorting & Pagination** — Navigate the film collection with organized sorting and page controls.
- 🎞️ **Film Details** — Explore film metadata, tags, and featured labels.
- ▶️ **Viewing Options** — Access available film sources and viewing links.
- ❤️ **My List** — Save films to a personal watchlist, remove individual entries, or clear the list with a confirmation dialog.
- 🌐 **AI Cinema Platforms** — Explore platforms related to AI cinema.
- 📱 **Responsive Interface** — A modern layout designed to adapt to different screen sizes.
- ⚡ **Optimized Hero Image** — Uses WebP compression to reduce image loading weight.
- 💾 **Persistent Watchlist** — Saves your list in browser Local Storage so it remains available after refreshing the page.
- 🎨 **Custom Branding** — Includes a custom favicon and a consistent cinema-inspired visual identity.

## 🚀 Getting Started

Follow these steps to run AI Cinema Universe locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Melvin-12143031/ai-cinema-universe.git
```

**2. Navigate to the project directory**

```bash
cd ai-cinema-universe
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL** provided in your terminal.

### Production Commands

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

Check the code with ESLint:

```bash
npm run lint
```
